# Lienzo 0.5.2

La ventana de Actualizaciones recupera el detalle sobrio: PC, commit en ejecución, versión y
commit disponibles, fecha de consulta y **Qué cambió**. Las novedades permanecen visibles
mientras prepara, compila, aplica y reconecta.

**Menú derecho → Actualizar** sigue iniciando directamente, sin un segundo botón de confirmación.
Si no hay novedades, no aparece la entrada ni «Al día». Se conservan la espera de Git, los errores
visibles y la protección contra aplicar dos veces al reabrir.

Publicar esta versión no la aplica ni reinicia Lienzo. La actualización anterior de Ariel terminó
correctamente en 0.5.1 antes de editar este cambio.

Verificación: 12 pruebas Chromium, incluyendo celular de 390 px; lint, TypeScript y compilación
aislada código 0. Capturas revisadas. Sin una nueva aceptación global. Ver [revisión](../../code-review-2026-10-19-updates-detail.md).
