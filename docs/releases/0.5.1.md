# Lienzo 0.5.1

Si pulsás **Actualizar** mientras Git consulta novedades, la ventana ahora espera esa consulta
y después aplica una sola actualización al commit que elegiste. Antes podía confundir la consulta
con una actualización en curso y quedar en «Iniciando» sin aplicar nada.

Muestra «Terminando consulta de novedades…». Un error de Git o una espera mayor a 90 segundos
se informa; no se transforma en éxito ni dispara una actualización. No aparece «Al día».

Publicar esta versión no la instala: queda disponible para el botón Actualizar de Ariel.
El cambio sólo afecta la interfaz del actualizador. Prolog mantiene la integración de 0.5.0.

Validación: 11 pruebas Chromium en build aislado, ESLint, TypeScript y build código 0. La prueba
del caso checking falla contra 0.5.0 y pasa con la corrección. Runner de lint y unitarias igual al
baseline. Sin nueva aceptación global ni actualización real automática. Ver [revisión](../../code-review-2026-10-19-updates-check.md).
