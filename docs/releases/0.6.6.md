# Lienzo 0.6.6

Auto-aprobar reconoce el permiso de comando de Antigravity con cabecera
`Requesting permission for:` y opciones `Yes, run command` / `No, cancel`.
Elige la ejecución actual; nunca las opciones persistentes `always allow`.
Hasta 0.6.5 el perfil devolvía None para todos los permisos de Antigravity y
la tarjeta mostraba equivocadamente «no es un permiso».

La regresión con el texto observado falló antes del cambio y pasó después.
Runner pruebas-agenticas: 239 pruebas focales aprobadas, 2757 deseleccionadas;
Ruff y diff check sin errores. Incluye el parser de pantalla, el proveedor de
auto-aprobación y casos negativos. No se enviaron teclas a sesiones reales
durante las pruebas; falta verificar la selección efectiva en Antigravity remoto.
No es una nueva aprobación global. Sigue pendiente el fallo WSL de 0.6.5.
