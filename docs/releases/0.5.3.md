# Lienzo 0.5.3

La etiqueta de la PC queda visible aunque haya una sola. Así no desaparecen sus opciones de
clic derecho, incluida **Actualizar** cuando hay novedades. Con una PC no se muestra el filtro
Todas redundante ni se cambia el tablero al pulsar su etiqueta. Con varias, los filtros siguen igual.

Se conserva la ventana sobria con novedades y avance, sin otro botón de confirmación.
Publicar esta versión no aplica la actualización ni reinicia Lienzo.

Verificación: 32 pruebas Chromium, lint, TypeScript y build aislado aprobados. Runner lint/unit
igual al baseline. Sin nueva aceptación global. Ver [revisión](https://github.com/arielelevy/lienzo/blob/ef3f92052b8ca4123866f825ff5c20ca82abb0ad/code-review-2026-10-19-single-pc.md).
