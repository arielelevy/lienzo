# Lienzo 0.3.0

Claude Desktop y Codex Desktop pueden recibir el rol de coordinadora cuando su canal de envío está disponible. Si se pierde el canal, se puede retirar el rol desde la tarjeta. Los permisos de control de consola conservan sus restricciones.

La conexión de Claude ofrece reconexión explícita de un adaptador inactivo del mismo proceso. Conserva los registros de envío y no repite mensajes inciertos. Un adaptador saludable se conserva. El comando público se oculta cuando vence y puede renovarse; una respuesta tardía no aparece en otra tarjeta. La autorización del adaptador ocurre en la conversación Claude receptora.

La versión también reúne los cambios de las rondas autorizadas: registros de nivel, evidencia de patrones, informes pendientes en reglas, continuidad de identidad y consultas de memoria con descarte de respuestas tardías. Sus revisiones están en los archivos `code-review-2026-10-17*.md` de la raíz.

## Validación y alcance

El cierre Desktop pasó 116 pruebas backend y 21 recorridos de navegador con servicios simulados. La revisión de contratos posterior pasó otras 44 pruebas. Estas cifras se solapan y no equivalen a una suma de cobertura. Las escrituras hacia sesiones reales estuvieron bloqueadas en las pruebas de interfaz.

La primera batería global registró 2292 pruebas backend aprobadas, 6 fallidas y 3 omitidas; la interfaz registró 133 aprobadas y 3 fallidas. Se actualizaron dobles que todavía usaban la firma anterior de registro y la expectativa de transporte desconectado. El tablero fijo ahora aísla avisos, consultas y memoria de las sesiones reales: su llegada tardía desplazaba las tarjetas durante las mediciones. No se relajaron los límites de movimiento ni se aprobaron baselines nuevos.

La batería global final pasó los siete casos: 2298 pruebas backend aprobadas y 3 omitidas, 136 de interfaz aprobadas, memoria focal con 153 aprobadas, memoria E2E, lint, build y unitarias con código 0. Las seis mutaciones aprobadas se midieron en una copia aislada del mismo estado Git: las cinco destructivas fueron detectadas y el control inocuo sobrevivió. La compuerta final devolvió PASS. La primera medición aislada se había detenido por rendimiento de memoria: 344,1 ms frente a un límite de 200 ms. El segundo intento pasó sin cambiar fuentes ni umbral; queda registrada la intermitencia. Detalle en `code-review-2026-10-17-desktop.md`.

## Límites pendientes

- Sigue abierta la P0 de Codex CLI después de `/new`: un handle de rollout estable y un ACK pueden pertenecer al hilo anterior, sin demostrar entrega en la consola visible. La reproducción está en `PENDIENTES.md`. Esta versión no certifica ese recorrido.
- La reconexión real de Claude requiere ejecutar y aprobar el comando vigente dentro de la conversación receptora. Las pruebas con fixtures no sustituyen esa confirmación.
- Los módulos Python nuevos necesitan un reinicio coordinado del servidor. Las rondas activas de otros proyectos deben conservarse.
- Codex Desktop es el destino de esta integración. Los chats generales de ChatGPT Desktop no están incluidos.
