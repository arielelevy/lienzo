# Lienzo 0.6.5

Antigravity conserva acceso al historial cuando su actualizador renombra la imagen
en ejecución a `agy.exe.<dígitos>.old`. Se mantiene el directorio oficial, el hash
conocido y las verificaciones de identidad y propiedad. No habilita fin/on_stop.

Las transferencias firman los pedidos después de conectar, conservando keep-alive
y reintentos. La espera del límite de red/disco se interrumpe al pausar y devuelve
el presupuesto reservado. La regresión de reanudación sincroniza la pausa después
de confirmar un archivo real.

Validación mediante el plugin pruebas-agenticas, roles secuenciales, sin modificar
baseline: focal backend de Antigravity/xfer con 211 aprobadas, 6 omitidas,
2772 deseleccionadas y 1 falla. Lint, build, unitarias y 139 recorridos UI aprobados.
Ruff y git diff --check sin errores. No se repitió la batería global completa ni
se midió mutación nueva.

**Falla conocida reproducida:** `test_wsl_unc_diez_cierres_inmediatos`, con
FileNotFoundError/WinError 2 en `os.fstat` de `_abrir_seguro` durante r_cerrar.
No se resolvió ni se ocultó; no hay PASS global. La publicación no cierra los
pendientes de WSL, uso remoto, cursor o coordinación de memoria.
