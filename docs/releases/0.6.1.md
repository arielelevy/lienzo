Chrome reemplaza posiciones pendientes compatibles, conservando el orden de teclas,
botones, liberaciones, ruedas y cambios de selección. Informa explícitamente cuando un
movimiento fue reemplazado; esa respuesta nunca confirma una tecla como ejecutada.

previos, lint y build correctos. Son pruebas con fixtures; falta acreditar la mejora del
incidente real en la LAN después de actualizar ambas puntas. [Revisión](../../review/2026-10-21/code-review-puntero-remoto.md).

del handle. Una respuesta obsoleta de `exists` ya no autoriza descartar un parcial válido.

mantiene la semántica de reinicio. Se conservan confinamiento, rechazo de enlaces y hashes.
Los errores nativos de publicación conservan además el NTSTATUS para continuar el diagnóstico.
